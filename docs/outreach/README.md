# Outreach Drafts

> 6 templates: 3 for Indie-Mom-Test, 3 for Agency-Discovery. Match each to a row in [`recruitment.md`](../../recruitment.md).

> **Brand-voice rules** (PRD §2 + Handbook ch 2):
> - **No future-tense questions.** Never "would you use…?"
> - **Subject ≤ 60 chars.** Inbox-preview real estate.
> - **Body ≤ 120 words.** Read in 30 seconds.
> - **One specific ask.** 15 minutes, named time, named topic.
> - **No multi-step CTA.** One link, one ask, one signoff.
> - **No emoji.** PRD constraint #5 (severity bands, no vibe).
> - **No "exciting opportunity."** PRD constraint #7 (Skeptic Mentor, not Friendly Co-Pilot).

## Templates

### Indie

- **[`indie-warm-intro.md`](./indie-warm-intro.md)** — when you have a mutual connection.
- **[`indie-cold-but-specific.md`](./indie-cold-but-specific.md)** — when you don't, but you've read their work.
- **[`indie-build-in-public-reply.md`](./indie-build-in-public-reply.md)** — public-thread reply that turns into a DM.

### Agency

- **[`agency-warm-intro.md`](./agency-warm-intro.md)** — friend-of-friend connection.
- **[`agency-cold-discovery.md`](./agency-cold-discovery.md)** — direct outreach to an agency founder/CEO.
- **[`agency-conference-followup.md`](./agency-conference-followup.md)** — after seeing them speak / read a deep piece they wrote.

## Reply-rate expectations (PRD §1 Track-D1 priors)

| Template | Expected reply | Action threshold |
|---|---|---|
| `indie-warm-intro` | 50–80% | Below 40% → improve mutual-connection language. |
| `indie-cold-but-specific` | 8–15% | Below 5% → personalization weak. |
| `indie-build-in-public-reply` | 20–40% (of public-reply → DM rate) | Tracks differently — count "DM accepted" not "reply." |
| `agency-warm-intro` | 50–80% | Below 40% → reframe ask. |
| `agency-cold-discovery` | 3–8% | Below 2% → wrong segment or wrong subject. |
| `agency-conference-followup` | 30–50% | Below 20% → too generic. |

## Anti-patterns to remove on sight

- "Hi {{firstName}}!" — visible-template marker.
- "I'd love to hop on a quick call to learn about your needs." — vague + future-tense.
- "I'm building ValidationKit, a cross-vendor agent-file audit platform." — pitch, not ask.
- "Looking forward to your thoughts." — sign-off that says nothing.
- "P.S. We're offering 50% off for early adopters." — discount-bait in first contact.
- LinkedIn DM-spam patterns (PRD §2 Constraint #3 — Legitimate Channels Only).
