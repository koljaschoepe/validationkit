## Why this handbook exists

Indie-Hackers and Solopreneurs validate badly. The standard validation cycle is "post on Twitter, ask if people want this, ship the idea that gets 10 likes." That picks up vanity, not demand. Pre-Build-Validation that actually predicts revenue takes deliberate work — and a worldview that respects the user enough to risk hearing no.

This handbook is the playbook ValidationKit's `/validate` command operationalizes. Read it cover-to-cover before you start a validation sprint. Re-read the chapter that maps to your current question whenever you're stuck.

## How to use this

- Pre-Build-Validation Sprint customers ($4500): read this **first**. The sprint deliverables map to chapter 5–7.
- Indie-Hackers on the $19 Solo tier: read chapters 1–3 before you spend any money.
- Founders skeptical of validation theatre: chapter 1 + chapter 8 are the load-bearing pair.
